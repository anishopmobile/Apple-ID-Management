# Apple ID Management

پنل مدیریتی فارسی و راست‌چین برای مدیریت اطلاعات مشتریان؛ نصب دو مرحله‌ای امن، ورود مدیر و داشبورد آماری.

**هشدار:** تا پیش از اجرای `composer install --no-dev` و `npm ci && npm run build:assets` در زمان استقرار، وابستگی‌ها و فایل‌های استاتیک محلی آماده نیستند. راهنمای کامل استقرار پس از تکمیل سورس در همین فایل ارائه می‌شود.
