# گزارش Apple ID Card

## مسیر و رفتار فعلی

از سایدبار «گزارشات ← Apple ID Card» یا آدرس `index.php?route=reports_apple_id_card` وارد شوید. گزارش در قالب یک جدول، **هر رکورد ثبت‌شده حذف‌نشده** را در یک ردیف جداگانه نمایش می‌دهد؛ اگر یک مشتری چند Apple ID داشته باشد، هر رکورد او جدا نمایش داده می‌شود. ستون‌ها: نام مشتری، شماره موبایل، Apple ID و دکمه «دریافت خروجی PDF». شناسه رکورد نیز برای تمایز رکوردها نشان داده می‌شود.

یک کادر جستجو هم‌زمان نام مشتری، موبایل (با پشتیبانی از ارقام فارسی و پیش‌شماره ایران) و Apple ID را به‌صورت لحظه‌ای جستجو می‌کند. نمایش ۲۵، ۵۰ و ۱۰۰ رکورد، حرکت به صفحه بعد و قبل، و مرتب‌سازی با کلیک روی نام ستون‌ها کاملاً AJAX هستند و صفحه رفرش نمی‌شود. صفحه‌بندی در سرور اعمال می‌شود.

**دکمه PDF در این مرحله فقط رابط مرحله بعد را آماده می‌کند** و با کلیک، اعلام می‌کند که قالب/طرح کارت باید ابتدا تعیین شود؛ فایل PDF تولید نمی‌شود. پس از اعلام قالب موردنظر، تولید PDF در این بخش اضافه خواهد شد.

## منبع داده و حریم خصوصی

داده‌ها مستقیماً از جدول‌های فعلی `customers`، `apple_records`، `record_fields`، `record_values` و `record_deletions` خوانده می‌شوند و جدول یا داده جدیدی ایجاد نمی‌شود. مقادیر نام، موبایل و Apple ID ثبت‌شده در فیلدهای هر رکورد در اولویت‌اند؛ اگر موجود نباشند، از ستون‌های قدیمی مرتبط استفاده می‌شود. رکوردهای حذف‌شده در گزارش حضور ندارند.

فقط مدیر واردشده حق دسترسی به صفحه یا API `reports_apple_id_card_api` را دارد. API فقط GET می‌پذیرد. کوئری‌ها پارامتری هستند، حداکثر طول جستجو ۱۲۰ نویسه، تعداد نمایش محدود به ۲۵/۵۰/۱۰۰، مرتب‌سازی محدود به نام‌های مجاز، و تمام متن‌های پویا در سمت کاربر با `textContent` درج می‌شود تا داده مشتری قابلیت تزریق HTML نداشته باشد. API فقط چهار فیلد جدول (شناسه، نام، موبایل و Apple ID) را برمی‌گرداند و هیچ رمز عبور یا پاسخ سؤال امنیتی را منتشر نمی‌کند.

## تست

`tests/apple_id_card_integration.php` پس از تست‌های داده‌ساز اجرا می‌شود؛ موارد جستجوی سه‌گانه، ارقام فارسی، مقدار EAV و مقدار قدیمی، حذف منطقی، صفحه‌بندی ۲۵/۵۰/۱۰۰، مرتب‌سازی و ورودی‌های مخرب را بررسی می‌کند. مرورگر Chromium نیز جستجوی بدون رفرش، مرتب‌سازی صعودی/نزولی، تغییر تعداد و صفحه، زیرمنو و واکنش دکمه PDF را آزمایش می‌کند.
